# FnCTOD 评测脚本 - 版本验证指南

## 问题描述

用户报告运行 `run_fnctod_transfertod.py` 时看到旧版本输出：

```
=== FnCTOD on TransferTOD 评测 ===
找到 10 个对话
评测完成！
```

这表明用户正在运行旧版本（空运行）的脚本，而不是新版本（完整评测实现）。

## 新版本标识

新版本的脚本在运行时会显示明确的版本标识：


## 如何更新到新版本

### 步骤 1: 清除 Python 缓存

```bash
# 清除 __pycache__ 目录
find . -type d -name "__pycache__" -exec rm -rf {} + 2>/dev/null

# 清除 .pyc 文件
find . -type f -name "*.pyc" -delete 2>/dev/null
```

### 步骤 2: 检查 Git 分支

```bash
# 查看当前分支
git branch

# 应该在 copilot/fix-loglevel-warning-attribute 分支上
# 如果不是，切换到该分支：
git checkout copilot/fix-loglevel-warning-attribute
```

### 步骤 3: 拉取最新代码

```bash
git pull origin copilot/fix-loglevel-warning-attribute
```

### 步骤 4: 验证更新

```bash
# 使用诊断工具验证
python benchmark/check_fnctod_version.py

# 应该看到:
# ✅ 结论: 你正在使用 NEW VERSION (完整评测实现)
```

### 步骤 5: 运行评测

```bash
python benchmark/run_fnctod_transfertod.py --limit 10 --data-root .data/TransferTOD/
```

## 常见问题

### Q: 为什么我看到的还是旧版本输出？

**A**: 可能的原因：

1. **Python 缓存问题**
   - 解决方案：清除 `__pycache__` 和 `.pyc` 文件

2. **Git 分支问题**
   - 解决方案：确认在 `copilot/fix-loglevel-warning-attribute` 分支

3. **没有拉取最新代码**
   - 解决方案：`git pull origin <branch-name>`

4. **运行了错误的文件**
   - 解决方案：使用绝对路径或检查当前目录

### Q: 如何确认我有最新版本？

**A**: 运行诊断工具：

```bash
python benchmark/check_fnctod_version.py
```

如果看到 "✅ 结论: 你正在使用 NEW VERSION"，就是最新版本。

### Q: 新版本运行失败怎么办？

**A**: 

1. 使用 `--verbose` 查看详细日志：
   ```bash
   python benchmark/run_fnctod_transfertod.py --verbose --limit 2
   ```

2. 检查错误信息：
   - 初始化错误：可能缺少依赖或配置
   - 数据加载错误：检查数据路径和格式
   - LLM 错误：检查 API 密钥和配置

3. 查看完整堆栈跟踪以定位问题
