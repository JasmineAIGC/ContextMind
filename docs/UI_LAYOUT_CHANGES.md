## 主要改进

### 1. 左侧 - 对话区域（70%）

- **对话框**：Chatbot组件，高度600px
- **输入区**：输入框 + 发送按钮（同一行）
- **特点**：占据主要空间，专注对话交互

### 2. 右侧 - 配置面板（30%）

包含4个功能区：

**a) 场景配置（固定显示）**
- 场景选择：闲聊/客服/保险
- 模式选择：contextmind/dst
- 应用配置按钮
- 当前配置状态

**b) 高级设置（可折叠）**
- 历史轮数滑块（5-50）
- 启用摘要checkbox
- LLM摘要checkbox
- 应用设置按钮
- 设置状态显示

**c) 对话状态（可折叠）**
- JSON格式状态显示

**d) 操作按钮（固定显示）**
- 查看状态、重置对话
- 清空历史

### 3. 底部 - 使用指南（全宽）

- 场景说明表格
- 模式对比说明
- 使用技巧列表
- 注意事项提示

## 优势

1. **更大的对话空间** - 70%宽度，600px高度
2. **配置集中** - 所有配置在右侧一个面板
3. **清晰分隔** - 左右用边框分隔
4. **使用指南不占主空间** - 折叠在底部，需要时展开
