## Overview

The RiSAWOZ (Slot-Filling and Intent Detection in Chinese Task-Oriented Dialogue) dataset is a large-scale Chinese task-oriented dialogue dataset. This documentation covers:

- Integration with the ContextMind DST mode
- Custom file path support for data loading
- Evaluation metrics aligned with TransferTOD
- NLU format data support for DST evaluation
- Troubleshooting common issues
