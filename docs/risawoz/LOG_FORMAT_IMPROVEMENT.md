# RiSAWOZ日志格式改进文档

## 概述

根据用户反馈："上面的修改不对，输出的日志 还是没有区分性，不清晰。参考 dst 模式下 在 transferTOD 数据集上 的日志打印格式。"

本次改进将RiSAWOZ的日志输出格式完全对齐TransferTOD，提供更清晰、更易读的评测结果。

## 改进前后对比

### 改进前 - 问题

**问题1：轮次输出冗余**
```
--- 轮次 1 ---
系统: ...
用户: ...
期望状态: {'旅游景点-名称': '周庄古镇'}
提取状态: {'旅游景点-名称': '周庄古镇'}
槽位匹配: 1/1           ← 不统一
严格匹配: 是            ← 不必要
软匹配: 是              ← 不必要
```

**问题2：技术细节暴露过多**
```
【最终状态比较】
期望状态: {...}
提取状态: {...}

【标准化后状态】（用于比较）  ← 用户不关心标准化细节
标准化期望: {...}
标准化提取: {...}

✅ 匹配槽位 (1): {...}        ← 太详细
❌ 缺失槽位 (0): {}
⚠️  额外槽位 (0): {}
```

**问题3：缺少意图评测结果**
- 没有单独的意图评测section
- 不显示预测vs真值的对比
- 无法判断意图识别是否正确

### 改进后 - 解决方案

**改进1：简化轮次输出**
```
--- 轮次 1 ---
系统: ...
用户: ...
期望状态: {'旅游景点-名称': '周庄古镇'}
提取状态: {'旅游景点-名称': '周庄古镇'}
匹配数: 1/1             ← 与TransferTOD一致
```

**改进2：清晰的结果展示**
```
======================================================================
📊 对话评测结果
======================================================================

【槽位评测结果】
槽位准确率 (Slot Accuracy): 100.00%
联合准确率-严格 (Joint Accuracy Strict): 100.00%
联合准确率-软匹配 (Joint Accuracy Soft): 100.00%
精确率 (Precision): 100.00%
召回率 (Recall): 100.00%
F1分数 (F1 Score): 100.00%

最终期望状态: {'旅游景点-名称': '周庄古镇'}
最终提取状态: {'旅游景点-名称': '周庄古镇'}

【意图评测结果】
预测意图: Inform
真值意图: Inform
评测结果: ✓ 正确
======================================================================

```

## 改进要点详解

### 1. 轮次输出简化

**改进前**：
```python
print(f"槽位匹配: {turn_correct_slots}/{turn_total_slots}")
print(f"严格匹配: {'是' if turn_exact_match_strict else '否'}")
print(f"软匹配: {'是' if turn_exact_match_soft else '否'}")
```

**改进后**：
```python
print(f"匹配数: {turn_correct_slots}/{turn_total_slots}")
```

**理由**：
- TransferTOD只显示"匹配数: X/Y"
- "严格匹配"和"软匹配"是内部计算，用户不需要看到
- 保持输出简洁清晰

### 2. 移除技术细节

**移除内容**：
- `【标准化后状态】` - 标准化是内部处理，用户不关心
- `✅ 匹配槽位` - 过于详细，从最终状态已可看出
- `❌ 缺失槽位` - 可以通过对比最终状态得知
- `⚠️ 额外槽位` - 同上

**保留内容**：
- `最终期望状态` - 必要的ground truth
- `最终提取状态` - 必要的预测结果

**理由**：
- 用户关心的是最终结果，不是中间过程
- 详细的槽位对比可以从最终状态直接看出
- 减少信息噪音，提高可读性

### 3. 添加意图评测结果

**新增section**：
```
【意图评测结果】
预测意图: Inform
真值意图: Inform
评测结果: ✓ 正确
```

**实现代码**：
```python
# 推断真值意图（从intent_evaluator）
inferred_intent, _ = self.intent_evaluator.infer_intent_from_slots(
    domain=dialogue.domain,
    turn_updates={},
    previous_state={},
    user_utterance=' '.join([turn.user_utterance for turn in dialogue.turns])
)

print("\n【意图评测结果】")
print(f"预测意图: {dialogue_intent}")
print(f"真值意图: {inferred_intent}")

# 使用标准化映射进行比较
norm_predicted = self.intent_evaluator.normalization_mapping.get(
    dialogue_intent.lower(), dialogue_intent.lower()
)
norm_inferred = self.intent_evaluator.normalization_mapping.get(
    inferred_intent.lower(), inferred_intent.lower()
)
is_correct = norm_predicted == norm_inferred
result = "✓ 正确" if is_correct else "✗ 错误"
print(f"评测结果: {result}")
```

**理由**：
- 与TransferTOD格式完全一致
- 清晰显示意图预测结果
- 方便用户判断意图识别是否准确

### 4. 结构优化

**section顺序**：
1. 【槽位评测结果】- 主要指标
2. 最终状态显示 - 验证数据
3. 【意图评测结果】- 辅助指标

**理由**：
- 与TransferTOD完全一致
- 先显示最重要的槽位指标
- 再显示辅助的意图指标
- 逻辑清晰，易于理解

### 5. 添加空行分隔

**改进**：
```python
print("=" * 70)
print()  # 添加空行分隔不同对话
```

**理由**：
- 每个对话结果后添加空行
- 更容易区分不同对话的结果
- 提高可读性
