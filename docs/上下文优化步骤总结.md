# ContextMind 上下文优化完整步骤与操作总结

> **项目目标**: 将 ContextMind 开发为一个通用的上下文优化框架，能够灵活集成各种上下文优化paper方案

## 一、上下文优化的11个核心步骤

基于对 ContextMind 现有实现的深入分析（主要来自 `engine.py` 的 `process_turn` 方法），我们识别出上下文优化包含以下11个核心步骤：

### 步骤1: 输入验证与预处理 (Input Validation & Preprocessing)

**目的**: 确保用户输入的有效性和规范性

**所有操作**:
1. **非空验证**: 检查输入是否为空字符串
2. **文本清洗**: 去除首尾空白字符 (`strip()`)
3. **长度检查**: 验证输入长度是否在合理范围内
4. **编码规范化**: 确保文本编码一致
5. **特殊字符处理**: 处理或转义特殊字符（可选）

**当前实现**:
```python
user_input = user_input.strip()
if not user_input:
    raise ValueError("User input must be non-empty.")
```

**可扩展方向**:
- 多语言检测与处理
- 敏感词过滤
- 输入意图预判断
- 输入格式标准化

### 步骤2: 会话管理 (Session Management)

**目的**: 管理对话会话的生命周期和状态

**所有操作**:
1. **会话存在性检查**: 检查是否已有活跃会话
2. **创建新会话**: 为新用户或新对话创建会话
   - 生成唯一 `session_id`
   - 初始化会话元数据
3. **获取现有会话**: 从SessionService读取会话
4. **会话状态更新**: 更新交互次数、时间戳等
5. **会话持久化**: 保存会话状态到存储
6. **会话超时检查**: 检查会话是否过期（可选）
7. **会话清理**: 清理过期或无用会话（可选）

**当前实现**:

### 步骤3: 上下文信息收集 (Context Collection)

**目的**: 从多个来源收集所有相关的上下文信息

这是最复杂的步骤，包含多个子操作：

#### 3.1 短期历史收集 (Recent History Collection)

**操作**:
1. **获取最近N条事件**: 从session读取最近的对话记录
2. **事件过滤**: 过滤掉无效或系统内部事件
3. **事件格式化**: 转换为统一的文本格式
4. **角色标注**: 标记每条消息的发送者（user/assistant）

**当前实现**:
```python
async def _collect_recent_history(self) -> str:

def _render_events(events: Sequence[Event]) -> str:
    lines = []
    for event in events:
        text = _content_to_text(event.content).strip()
        if not text:
            continue
        speaker = "User" if event.author == "user" else event.author
        lines.append(f"{speaker}: {text}")
    return "\n".join(lines)

#### 3.2 长期记忆检索 (Long-term Memory Retrieval)

**操作**:
1. **查询构建**: 从用户输入构建搜索查询
   - 原始查询
   - 关键词提取
   - 语义变体生成
2. **并发多查询检索**: 使用多个查询并发搜索
3. **结果去重**: 移除重复的记忆条目
4. **相关性评分**: 计算每条记忆的相关性分数
   - 关键词匹配分数 (40%)
   - 重要性标签分数 (30%)
   - 时间衰减分数 (30%)
5. **结果排序**: 按相关性分数降序排列
6. **结果截断**: 保留top-K条最相关记忆
7. **结果格式化**: 转换为文本格式

**当前实现**:
```python

```python
def _calculate_relevance_score(self, memory_text: str, query: str, timestamp) -> float:
    score = 0.0
    
    # 1. 关键词匹配 (40%)
    if query.lower() in memory_text.lower():
        score += 0.4
    else:
        # 部分匹配
        query_words = set(query.lower().split())
        memory_words = set(memory_text.lower().split())
        overlap = len(query_words & memory_words)
        score += 0.4 * (overlap / len(query_words))
    
    # 2. 重要性标签 (30%)
    importance_tags = {
        "[重要事实]": 0.3,
        "[关键事件]": 0.3,
        "[对话总结]": 0.25,
        # ...
    }
    for tag, tag_score in importance_tags.items():
        if tag in memory_text:
            score += tag_score
            break
    
    # 3. 时间衰减 (30%)
    # 1天内: 1.0, 7天内: 0.8, 30天内: 0.6, 更久: 0.4
    time_diff = (now - memory_time).total_seconds()
    if time_diff < 86400:
        time_score = 1.0
    # ...
    score += 0.3 * time_score
    
    return score
```

### 步骤5: Prompt生成 (Prompt Generation)

**目的**: 基于整合的上下文生成优化的、结构化的prompt

这是核心步骤之一，有多种策略：

**操作**:
1. **构建Meta-Prompt**: 为LLM构建指导性prompt
2. **调用LLM**: 使用LLM作为prompt工程师
3. **超时控制**: 设置超时避免无限等待
4. **质量验证**: 验证生成的prompt长度和有效性
5. **提取实际内容**: 从LLM输出中提取prompt

#### 5.2 模板Prompt生成 (Template-based)

**操作**:
1. **计算上下文权重**: 为每个上下文源计算权重
2. **上下文排序**: 按权重降序排序
3. **模板选择**: 选择合适的模板
4. **信息填充**: 将上下文填入模板
5. **重要性标记**: 标记高权重信息
6. **长度控制**: 截断过长内容
7. **格式化**: 美化输出格式

**上下文权重计算操作**:
```python
def _calculate_context_weights(self, knowledge: IntegratedKnowledge) -> dict:
    weights = {
        'history': 0.5,
        'memory': 0.3,
        'preset': 0.1,
        'extended': 0.1
    }
    
    # 动态调整：有长期记忆时提升权重
    if knowledge.memory_text:
        weights['memory'] = 0.8
        weights['history'] = 0.6
    
    # 动态调整：业务关键词匹配
    business_keywords = ["额度", "费用", "申请", ...]
    if any(kw in knowledge.user_input for kw in business_keywords):
        weights['preset'] = 0.7
    
    # 动态调整：情绪关键词匹配
    emotion_keywords = ["骚扰", "报警", "拒绝", ...]
    if any(kw in knowledge.user_input for kw in emotion_keywords):
        weights['memory'] = 0.9
    
    return weights
```

**模板拼接操作**:
```python
def _build_prompt(self, knowledge: IntegratedKnowledge) -> str:
    prompt_parts = [knowledge.base_system_prompt]
    
    # 计算权重
    weights = self._calculate_context_weights(knowledge)
    
    # 排序上下文
    context_items = [
        ('memory', knowledge.memory_text, '长期记忆'),
        ('history', knowledge.history_text, '近期对话历史'),
        ('preset', knowledge.preset_info, '预置信息'),
        ('extended', knowledge.extended_context, '扩展上下文')
    ]
    sorted_items = sorted(context_items, key=lambda x: weights[x[0]], reverse=True)
    
    # 添加用户输入（最高优先级）
    prompt_parts.append(f"\n【当前用户输入】\n{knowledge.user_input}")
    
    # 按权重添加上下文
    for key, content, label in sorted_items:
        if not content or weights[key] < 0.1:
            continue
        
        if weights[key] > 0.6:
            prompt_parts.append(f"\n【重要参考：{label}】\n{content}")
        else:
            prompt_parts.append(f"\n【一般参考：{label}】\n{content}")
    
    return "\n".join(prompt_parts)
```

**当前实现**:
```python
async def _generate_response_with_retry(self, prompt: str) -> str:
    max_retries = 3
    
    for attempt in range(max_retries):
        try:
            reasoning, response = self._llm_client.generate(prompt)
            response = self._extract_actual_response(response)
            
            # 质量验证
            response = response.strip()
            if not response or len(response) < 5:
                continue
            
            # 检查是否包含分析性内容
            analysis_keywords = ['首先', '然后', '分析', ...]
            if any(keyword in response for keyword in analysis_keywords):
                continue
            
            # 检查是否过长
            if len(response) > 80:
                continue
            
            break
                
        except Exception as e:
            if attempt < max_retries - 1:
                logger.debug(f"重试 {attempt + 1}/{max_retries}")
                continue
            else:
                raise RuntimeError(f"生成失败: {e}")
    
    return response
```

### 步骤7: 响应后处理 (Post-processing)

**目的**: 清洗和规范化LLM生成的响应

**所有操作**:
1. **格式清洗**:
   - 去除Markdown标记 (`**`, `` ` ``, `#`等)
   - 去除JSON格式标记 (`{}`, `[]`)
   - 去除引号标记 (`"`, `「」`, `""`)
2. **内容提取**:
   - 提取关键回复部分
   - 移除分析过程
   - 移除思考痕迹
3. **内容验证**:
   - 长度检查
   - 禁用词检查
   - 格式检查
4. **规范化**:
   - 统一标点符号
   - 去除多余空白
   - 首字母大写（可选）
5. **安全检查**:
   - 敏感信息过滤
   - 违规内容检测

**当前实现**:
```python
@staticmethod
def _extract_actual_response(response: str) -> str:
    response = response.strip()
    
    # 移除JSON格式
    if response.startswith('{') and response.endswith('}'):
        try:
            data = json.loads(response)
            if 'content' in data:
                return str(data['content']).strip()
        except:
            pass
    
    # 移除外层引号
    if (response.startswith('"') and response.endswith('"')):
        response = response[1:-1].strip()
    
    # 处理结构化格式
    if '**' in response and '：' in response:
        lines = response.split('\n')
        for line in lines:
            if '：' in line and not line.startswith('**'):
                content = line.split('：', 1)[1].strip()
                if content and len(content) > 5:
                    return content
    
    # 移除markdown标记
    response = re.sub(r'\*\*(.*?)\*\*', r'\1', response)
    response = re.sub(r'`(.*?)`', r'\1', response)
    
    # 提取引号内容
    quoted = re.findall(r'["""]([^"""]+)["""]', response)
    if quoted:
        return quoted[-1].strip()
    
    # 提取关键词后内容
    patterns = [
        r'回复应为[：:]\s*["""]?([^"""\n]+)["""]?',
        r'回复[：:]\s*["""]?([^"""\n]+)["""]?',
    ]
    for pattern in patterns:
        match = re.search(pattern, response)
        if match:
            return match.group(1).strip()
    
    return response
```

```python
async def _extract_knowledge_from_session(self, session: Session) -> dict:
    knowledge = {
        "user_profile_updates": {},
        "key_events": [],
        "user_preferences": {},
        "important_facts": [],
        "emotional_state": None
    }
    
    history_text = _render_events(session.events)
    
    extraction_prompt = f"""请从以下对话中提取关键信息，严格按照JSON格式输出：

对话历史：
{history_text}

请提取以下信息（只输出JSON对象）：
{{
  "user_profile_updates": {{}},
  "key_events": [],
  "user_preferences": {{}},
  "important_facts": [],
  "emotional_state": null
}}"""

    _, result = self._llm_client.generate(extraction_prompt)
    result = self._extract_actual_response(result)
    
    # 清洗和解析
    cleaned_result = result.strip()
    if cleaned_result.startswith('```json'):
        cleaned_result = cleaned_result[7:]
    if not cleaned_result.endswith('}'):
        cleaned_result = self._repair_truncated_json(cleaned_result)
    
    parsed = json.loads(cleaned_result)
    knowledge.update(parsed)
    
    return knowledge

def _repair_truncated_json(self, json_str: str) -> str:
    open_braces = json_str.count('{')
    close_braces = json_str.count('}')
    if open_braces > close_braces:
        json_str += '}' * (open_braces - close_braces)
    return json_str
```

async def _periodic_summary(self) -> None:
    interval = self.user_state.summary_interval
    if interval <= 0:
        return
    
    # 检查是否到达总结间隔
    if self.user_state.interaction_count % interval != 0:
        return
    
    session = await self._fetch_session()
    if not session.events or len(session.events) < 2:
        return
    
    history_text = _render_events(session.events)
    
    summary_prompt = f"""请总结以下对话历史，生成高层次的知识摘要：

对话历史：
{history_text}

请生成一个简洁的知识摘要，包括：
1. 用户的核心特征和画像更新
2. 对话的主要进展和结果
3. 用户态度和情绪的变化趋势
4. 需要长期记住的关键信息

总结要求：
- 简洁明了，不超过150字
- 只输出总结内容
- 侧重于需要长期记住的信息"""

    _, summary = self._llm_client.generate(summary_prompt)
    summary = self._extract_actual_response(summary)
    
    if summary and len(summary) > 10:
        summary_event = Event(
            invocation_id=self._new_invocation_id(),
            author="system",
            content=Content(role="system", parts=[Part(text=f"[对话总结] {summary}")]),
        )
        await self.session_service.append_event(session=session, event=summary_event)
